Status: prepared, pending real participants. Use an isolated preview or loopback database with fictitious accounts. Obtain permission to take anonymous notes and record only task evidence. Keep the dashboard demo separate and use a pre-created editor session without showing credentials.

1. Starting from the homepage, explain what the shop offers and find the commercial.
2. Find a recommendation through Finder. Explain it and identify the alternative.
3. Compare three flavours and indicate one meaningful difference and the price.
4. Build a four-cookie box, replace one cookie, identify the total and review the basket.
5. Submit an isolated fictional order and find its reference and print action.
6. Repeat one task on mobile. Repeat the main ordering task using only the keyboard.
