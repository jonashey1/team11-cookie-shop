# Cookie Shop public knowledge base

> This record describes the implementation or evidence at the stage named below. See the [current release evidence](../../current-release-evidence.md) for the latest verified status.

Cookie Shop is a fictional UGent university project. There are no real payments, deliveries, bookings, pickup locations or customer support services. Verified allergen and nutrition information is unavailable. Never infer suitability for an allergy or diet.

- [Assortment and Taste Map](https://team11-cookie-shop.vercel.app/workshops#taste-map). The two axes reuse qualitative sweetness and chocolate intensity profiles. Pick a product with a marker or its name and add it to the existing comparison.
- [Cookie Finder and Passport](https://team11-cookie-shop.vercel.app/cookie-finder). Four answers and deterministic scoring produce a recommendation and an alternative. A passport shows what the user chose and offers a retake, comparison, basket and box links. No registration or saved personal taste profile.
- [Compare](https://team11-cookie-shop.vercel.app/compare). Compare two or three products. Highlight differences keeps all characteristics visible.
- [Build Your Own Box](https://team11-cookie-shop.vercel.app/build-your-box). Exactly four cookies, including duplicates. Remove and replace one slot independently. Optional name and message are local preview text only. Save/restore/remove the combination in the current browser; current catalogue prices apply.
- [Workshops](https://team11-cookie-shop.vercel.app/workshops#workshops). Browse the existing fictional baking and decorating demonstrations. Individual workshop pages link to related topics. These cannot be booked.
- [Order Cookies](https://team11-cookie-shop.vercel.app/clinics). Add selections, adjust quantities, review basket, provide made-up name and email and place a test order. The printable confirmation gives the saved reference. Never use real details.
- [Contact](https://team11-cookie-shop.vercel.app/contact) and [FAQ](https://team11-cookie-shop.vercel.app/faq) explain the project. The optional member area is disabled on production.
