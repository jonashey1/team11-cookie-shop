# Usability protocol

**Status:** protocol for a new session on the current release. Earlier observations and the reported retest are in [D6](test-report.md). An independent observation of the current comparison flow remains open.

Use a test environment with fictional records. Ask for consent to take anonymous notes. Do not record participant names, emails or production records.

## Introduction

We are testing the website, not you. Think aloud and use it as you normally would. Use the fictitious details provided. There is no payment, and you may stop at any time.

## Tasks

1. Locate a known flavour and add it to the basket.
2. Find a flavour recommendation and compare it with another choice. Explain your decision.
3. Fill a four-cookie box, replace one cookie without changing the other slots, then add it to the basket.
4. Change a quantity, remove a product and continue shopping. Return and explain the total.
5. Enter an invalid email, correct it and submit a fictional order. Identify the reference and print action.
6. Repeat the core order using keyboard only or a phone. Try an accessibility setting if useful.
